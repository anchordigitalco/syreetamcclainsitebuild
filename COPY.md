## Note on length

The abridgements were originally decided before the layout problem was understood, and this
file used to say "re-judge them after the composition pass ships." **That is now settled.**
The September 4 rewrite set the lengths deliberately: the word budget runs from ~20 words
(Contact) to ~110 (Educational Leader, Athletic Management), a roughly 5:1 spread that the
composition depends on being visible as section height. **Do not lengthen an abridged
section to fill space** — if a section looks thin in the build, that is a composition
problem, not a copy problem.
